# Data Desk — 你电脑上的数据分析平台 📊

> **数据在你电脑上，分析也在你电脑上。**
> 数据不外传——Excel、CSV 在你硬盘上直接算，变成"张嘴就能问的账"。

---

## 为什么是"本地"分析？

很多工具让你把表格传到别人的服务器上算。Data Desk 反过来：**引擎装在你电脑里，你的数据文件从头到尾不出你的硬盘。**（和 Agent 对话本身需要联网，但那传的是你的问题，不是你的数据。）

这意味着：

- 🔒 **敏感数据放心算**——工资表、客户名单、银行流水，数据文件不离开你的电脑
- 🧮 **算在哪很明确**——需要联网的只是你和 Agent 的对话；你的表格、查询结果、导出文件全程留在本机
- ⚡ **快**——DuckDB 引擎单机就能秒级扫百万行，比开 Excel 刷公式快得多
- 💾 **数据就是一个文件**——你的"数据库"其实是一个 SQLite 文件，拷贝、备份、发同事，跟发一个 Excel 一样简单
- 💰 **零成本**——没有账号、没有订阅、没有按量计费

**工作方式**：一个普通 SQLite 文件当"仓库"，DuckDB 当"算账先生"。它天生能直接读 CSV、Excel、JSON、Parquet——所以不管数据是散落的文件还是库里的表，都能放在一起算。

## 能干哪些活？

### 日常分析：说人话就行

| 你说 | 它给你 |
|---|---|
| "帮我把这个 CSV 存进数据库" | 自动建好表，告诉你存了多少行 |
| "上个月北京卖了多少？" | 直接报数字，附一句话解释 |
| "这份数据长什么样？" | 一张字段速览表：有哪些列、数据全不全 |
| "把这份 Excel 和库里的订单对一下" | 直接对上，标出对不上的地方 |
| "导出成 Excel / Parquet" | 一句话拿到转换好的文件 |

**招牌能力：跨格式联查**——库里存的表和硬盘上的 Excel、CSV、Parquet，可以放在同一次查询里互相 JOIN、对比汇总。不用先统一格式，不用导来导去。

### 财税分析：会说行话 🏦

你是会计、出纳、税务专员？说到"对账""发票""余额表"，它自动切换财税模式，按行规来算：

- **对银行流水**："帮我对一下银行流水" → 已核对笔数、未达项清单、差异合计，还能导出成可直接归档的《未达项清单.xlsx》
- **核对进销项发票**："核对一下进销项发票" → 哪张票两边都有、哪张只有一边有、哪张重复了
- **余额表对比**："管理费用这个月比上月多了多少？" → "多 95,000 元（80,000 → 175,000），全部来自本期新增发生额，建议按明细科目再拆一层看。"

它懂行规：红冲 `(300.00)` 自动按 -300 抵减；千分位、¥ 符号自动剥掉再算；`2026/9/1` 和 `2026-09-01` 混在一列也认得；读不懂的行**明明白白列出来**，绝不偷偷丢掉。

### 格式转换：一句话的事

CSV ⇄ Excel ⇄ Parquet ⇄ JSON ⇄ SQLite，随口说一句就转好。分析结果也能直接导出成带表头的 Excel 底稿，拿来归档、转发、打印都行。

## 三步上手

**第 1 步**：装一个免费小工具（装一次就行）

- macOS：`brew install duckdb`
- Windows：`winget install DuckDB.cli`

**第 2 步**：在 WorkBuddy 里启用 data-desk 技能

**第 3 步**：把文件丢过来，开问。

也可以用命令行干活（适合喜欢敲命令的朋友）：

```bash
python scripts/data-desk.py init ./data/main.sqlite          # 建个"仓库"
python scripts/data-desk.py import ./data/main.sqlite 销售表.xlsx   # 文件存进去
python scripts/data-desk.py tables ./data/main.sqlite         # 看看里面有什么
python scripts/data-desk.py convert 报表.xlsx 报表.parquet     # 格式随便转
```

## 常见问题

**Q：数据真的不会外传吗？**
不会。所有计算都由你电脑上的 DuckDB 完成，你的数据文件、查询结果、导出文件全程留在本机。联网的部分只是你和 Agent 的对话（就像你不会把账本交给聊天软件，只是问它问题）。涉及删除、覆盖的操作它都会先问你。

**Q：我的 Excel 很乱，能用吗？**
大概率能。表头不在第一行、一个文件好几个 sheet、金额带文字格式——都是财务表格的日常，它见过。真读不了时，它会用人话告诉你哪里不行、怎么改，不甩报错码。

**Q：要不要学 SQL？**
不用。会说话就会用。（想看 SQL 的话，它也乐意写给你。）

**Q：文件太大怎么办？**
超过百万行它不会闷头硬算，会先告诉你预计规模，问你要不要继续。

## 给技术同学：项目一览

```text
data-desk/
├── SKILL.md                    # 技能主文件：路由 + 领域识别 + 核心任务
├── references/
│   ├── caishui.md              # 财税领域包：入门、术语表、3 个配方、清洗惯用法
│   ├── friendly-sql.md         # DuckDB SQL 惯用法
│   └── sqlite-cookbook.md      # SQLite 操作手册
├── scripts/data-desk.py        # 跨平台辅助脚本
└── specs/                      # 特性规范（Spec Kit 全流程，可追溯）
```

**架构一句话**：基础引擎（本地 SQLite 仓库 + DuckDB 引擎）只管通用数据活儿；行业知识按"领域包"挂载，目前有财税（caishui），以后可以加更多行业。

**设计原则**：主文件精炼、细节进手册、破坏性操作先确认、数据不出本机、文档人人能看懂。
